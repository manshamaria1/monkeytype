A complete typing test for your site: speed tests, accounts, statistics, leaderboards, multiplayer races, lessons and achievements.

== Description ==

Add `[typing_test]` to any page.

* Typing tests: time (15/30/60/120 s or custom), words, quotes, custom text, practice; punctuation, numbers, difficulty, strict mode.
* 9 languages: English, Spanish, French, German, Portuguese, Hindi, Urdu, Punjabi, Arabic.
* Accounts are your site's WordPress users. Results, settings, statistics and personal records are saved to their account.
* Leaderboards (today, this week, this month, all time) by test length, language and country. Every result is re-checked on the server from its keystroke log.
* Multiplayer races with room codes and invite links.
* Lessons with finger guidance, daily challenge, weak-key drills, goals and achievements.
* 13 themes, fonts, caret styles, sounds.

`[typing_test view="test"]` shows only the typing test.

== Requirements ==

* MySQL 8.0+ or MariaDB 10.2+ (for leaderboards).
* Turn on Settings → General → "Anyone can register" so visitors can create accounts.

== Installation ==

1. Plugins → Add New → Upload Plugin → choose typing-test.zip → Install → Activate.
2. Pages → Add New → add a Shortcode block with `[typing_test]` → Publish.
